# 🌤️ OpenWeatherMap API 사용 가이드

## 📋 개요

OpenWeatherMap은 무료 날씨 API를 제공하는 서비스입니다. JSP 프로젝트에서 날씨 정보를 가져와서 활용할 수 있습니다.

**공식 사이트:** http://openweathermap.org/

---

## 🔑 1. API 키 발급

### 1.1 회원가입

1. http://openweathermap.org/ 접속
2. 우측 상단 **Sign in** 클릭
3. **Create an Account** 또는 **Sign Up** 클릭하여 회원가입

### 1.2 API 키 복사

1. 로그인 후 상단 메뉴에서 **API keys** 탭 클릭
2. 생성된 API 키 복사
   - 예시: `cd63accc133fc76e1f94a3f270442688`

**⚠️ 주의:** API 키는 개인 정보이므로 공개하지 마세요!

---

## 🏙️ 2. 도시 코드 찾기

### 2.1 도시 검색 방법

1. 메인 화면의 **돋보기(검색창)** 클릭
2. **"Search city"** placeholder 부분에 도시명 입력
   - 예: `Hanam` (하남)
   - 예: `Seoul` (서울)
3. 검색된 도시 클릭
4. 날씨 정보 페이지에서 **주소표시줄** 확인

### 2.2 도시 코드 확인

**주소 형식:**
```
https://openweathermap.org/city/1897007
```

**오른쪽 숫자가 도시 코드입니다.**

**주요 도시 코드:**
- 하남: `1897007`
- 서울: `1835848`

## 🌐 3. API 엔드포인트

### 3.1 기본 URL 구조

```
http://api.openweathermap.org/data/2.5/{endpoint}?id={city_id}&appid={API_key}
```

**파라미터:**
- `{endpoint}`: API 종류 (forecast, weather 등)
- `{city_id}`: 도시 코드
- `{API_key}`: 발급받은 API 키

### 3.2 Forecast API (예보)

**5일간의 날씨 예보를 제공합니다.**

**URL:**
```
http://api.openweathermap.org/data/2.5/forecast?id={city_id}&appid={API_key}
```

**예시:**
```
http://api.openweathermap.org/data/2.5/forecast?id=1897007&appid=cd63accc133fc76e1f94a3f270442688
```

**응답 데이터:**
- 5일간의 날씨 예보 (3시간 간격)
- 온도, 습도, 날씨 설명, 아이콘 등

### 3.3 Weather API (현재 날씨)

**현재 날씨 정보를 제공합니다.**

**URL:**
```
http://api.openweathermap.org/data/2.5/weather?id={city_id}&appid={API_key}
```

**예시:**
```
http://api.openweathermap.org/data/2.5/weather?id=1897007&appid=cd63accc133fc76e1f94a3f270442688
```

**응답 데이터:**
- 현재 날씨 정보
- 온도, 습도, 날씨 설명, 아이콘 등

## 🌡️ 4. 온도 단위 설정

### 4.1 기본 단위 (Kelvin)

기본적으로 온도는 **Kelvin (켈빈)** 단위로 반환됩니다.

**예시:**
```json
{
  "main": {
    "temp": 279.23
  }
}
```

### 4.2 섭씨(Celsius)로 변경

**파라미터 추가:** `&units=metric`

**예시:**
```
http://api.openweathermap.org/data/2.5/forecast?id=1897007&appid=cd63accc133fc76e1f94a3f270442688&units=metric
```

**응답:**
```json
{
  "main": {
    "temp": 6.08  // 섭씨 온도
  }
}
```

### 4.3 화씨(Fahrenheit)로 변경

**파라미터 추가:** `&units=imperial`

**예시:**
```
http://api.openweathermap.org/data/2.5/forecast?id=1897007&appid=cd63accc133fc76e1f94a3f270442688&units=imperial
```

### 4.4 온도 단위 비교

| 단위 | 파라미터 | 예시 온도 |
|------|----------|-----------|
| Kelvin | (기본값) | 279.23 |
| Celsius | `&units=metric` | 6.08 |
| Fahrenheit | `&units=imperial` | 42.94 |

## 🎨 5. 날씨 아이콘 사용

### 5.1 아이콘 코드 확인

**공식 문서:** https://openweathermap.org/weather-conditions

**아이콘 코드 형식:**
- 예: `10d` (light rain, 낮)
- 예: `01n` (clear sky, 밤)

**코드 구조:**
- 앞 2자리: 날씨 코드 (01, 02, 03, 04, 09, 10, 11, 13, 50)
- 마지막 1자리: 시간대 (`d` = 낮, `n` = 밤)

### 5.2 아이콘 URL 생성

**기본 형식:**
```
https://openweathermap.org/img/wn/{icon_code}@2x.png
```

**예시:**
```
https://openweathermap.org/img/wn/10d@2x.png
```

**사용 예시:**
```html
<img src="https://openweathermap.org/img/wn/10d@2x.png" alt="날씨 아이콘">
```

### 5.3 API 응답에서 아이콘 코드 가져오기

**JSON 응답 예시:**
```json
{
  "weather": [
    {
      "id": 500,
      "main": "Rain",
      "description": "light rain",
      "icon": "10d"
    }
  ]
}
```

**JSP에서 사용:**
```jsp
<img src="https://openweathermap.org/img/wn/${weather.icon}@2x.png" 
     alt="${weather.description}">
```

## 1. OpenWeatherMap이 주는 것

브라우저가 아래 URL로 요청하면 **JSON**이 돌아옵니다.

```
https://api.openweathermap.org/data/2.5/weather?id=1835848&appid=키&units=metric
```

| 쿼리 | 의미 |
|------|------|
| `id=1835848` | 도시 번호. 1835848은 서울 |
| `appid=` | API 키 (발급받은 값) |
| `units=metric` | 온도를 섭씨(℃)로 |

키는 수업용 예제에 들어 있습니다. 실제 서비스에서는 키를 HTML에 그대로 두지 않는 것이 좋습니다.

### 1-1. 두 엔드포인트

| 파일 | URL 경로 | 응답 모양 |
|------|----------|-----------|
| `weather1.html` | `/data/2.5/forecast` | `list` 배열. 3시간 간격 예보 |
| 나머지 | `/data/2.5/weather` | **지금** 날씨. `list` 없음 |

예보(`forecast`)는 여러 시각이 배열로 옵니다. 예제는 **가장 가까운 시각 하나**만 씁니다.

```javascript
result.list[0].main.temp
result.list[0].weather[0].icon
result.list[0].dt_txt   // "2026-09-09 12:00:00"
```

현재 날씨(`weather`)는 바로 `main`을 꺼냅니다.

```javascript
result.main.temp
result.weather[0].icon
result.name             // "Seoul"
```

`weather`가 배열인 이유: 날씨 상태가 여러 개일 수 있어서입니다. 보통 **0번만** 사용합니다.

### 1-2. 자주 쓰는 JSON 경로

```text
resp
 ├── name                 도시명 (Seoul)
 ├── weather[0]
 │    ├── icon            "10d", "01n" ...
 │    └── description     "broken clouds" 등
 ├── main
 │    ├── temp            현재(또는 해당 시각) 온도
 │    ├── temp_min
 │    ├── temp_max
 │    └── humidity        습도
 ├── wind.speed           바람
 ├── clouds.all           구름량
 └── sys.country          국가 코드 (KR)
```

아이콘 이미지 주소 (OpenWeather 기본 그림):

```
https://openweathermap.org/img/wn/10d@2x.png
```

`10d` 자리를 `${아이콘코드}`로 바꿔 넣으면 됩니다.

## 2. weather1 — 예보 + $.getJSON

가장 짧은 요청 방법입니다.

```javascript
$.getJSON(url, function(result){
    let $ctemp   = result.list[0].main.temp;
    let $mintemp = result.list[0].main.temp_min;
    let $maxtemp = result.list[0].main.temp_max;
    let $cicon   = result.list[0].weather[0].icon;
    let $cDate   = result.list[0].dt_txt;

    $(".ctemp").append($ctemp);
    $('.clowtemp').append($mintemp);
    $('.chightemp').append($maxtemp);
    $('h2').prepend($cDate);
    $('.cicon').append(`<img src=https://openweathermap.org/img/wn/${$cicon}@2x.png>`);
});
```

포인트

- `$.getJSON`은 GET + JSON 파싱을 한 번에 합니다.
- `append`는 기존 글자 **뒤에** 붙입니다. `"현재 온도: "` 뒤에 숫자가 이어집니다.
- `prepend`는 **앞에** 붙입니다. `h2`가 `2026-09-09 12:00:00 | 날씨예보`가 됩니다.
- 아이콘은 `<img>`로 OpenWeather 그림을 넣습니다.

HTML 뼈대

```html
<h2> | 날씨예보</h2>
<div class="ctemp">현재 온도: </div>
<div class="clowtemp">최저 온도: </div>
<div class="chightemp">최고 온도: </div>
<div class="cicon">아이콘 :</div>
```

jQuery는 `<head>`에서 CDN으로 불러 옵니다.

```html
<script src="http://code.jquery.com/jquery-3.1.1.min.js"></script>
```

## 3. weather2 — 현재 날씨 + 오늘 날짜

URL만 `forecast` → `weather`로 바꾸고, 날짜는 API가 아니라 **브라우저 Date**로 만듭니다.

```javascript
let $ctemp   = result.main.temp;      // list[0] 없음
let $mintemp = result.main.temp_min;
let $maxtemp = result.main.temp_max;
let $cicon   = result.weather[0].icon;

let $now = new Date();
let $cDate = $now.getFullYear() + '-' + ($now.getMonth() + 1) + '-' + $now.getDate()
           + " / " + $now.getHours() + ":" + $now.getMinutes();

$('h2').prepend($cDate);
```

| 메서드 | 주의 |
|--------|------|
| `getMonth()` | **0부터** 시작 (1월 = 0) → 반드시 `+ 1` |
| `getDate()` | 일(day). `getDay()`는 요일(0=일)이라 다름 |
| 자리수 | `9`월이 `09`가 아니라 `9`로 나옴 (앞에 0 안 붙음) |

`weather1`은 예보 시각(`dt_txt`)을 쓰고, `weather2`는 **지금 PC 시각**을 씁니다.

## 4. weather_ajax1 — 데이터 모양 먼저 보기

화면보다 **콘솔**이 목적입니다. 어떤 키가 있는지 확인한 뒤 위젯을 만듭니다.

```javascript
$.ajax({
    url: apiURI,
    type: "GET",
    dataType: "json",
    async: false,
    success: function(resp) {
        console.log("현재 온도" + resp.main.temp);
        console.log("현재 습도" + resp.main.humidity);
        console.log("상세 날씨" + resp.weather[0].description);
        console.log("날씨 아이콘" + resp.weather[0].icon);
        console.log("바람 속도" + resp.wind.speed);
        console.log("현재 국가" + resp.sys.country);
        console.log("도시명" + resp.name);
        console.log("구름" + resp.clouds.all);
    },
    error: function(xhr, status, error) {
        console.error(error);
    }
});
```

`$.getJSON`과 하는 일은 비슷합니다. `$.ajax`는 **실패 처리(`error`)**, 전송 방식, 동기/비동기를 옵션으로 적을 수 있습니다.

`async: false`는 응답이 올 때까지 브라우저를 멈춥니다. 수업 예제용이고, 실무에서는 기본값(비동기, `true`)을 씁니다.

F12 → Console에서 숫자와 문자열이 찍히면 JSON 경로를 맞게 읽은 것입니다.

## 5. weather_ajax — 아이콘 위젯

콘솔 확인이 끝나면  squarish 박스에 **Font Awesome 아이콘 + 온도 + 도시명**을 넣습니다.

### 5-1. 아이콘 코드 → 클래스 이름

OpenWeather 아이콘은 `"01d"`, `"10n"`처럼 **앞 두 글자가 날씨 종류**, 뒤 `d`/`n`이 낮/밤입니다.

```javascript
let $Icon = (data.weather[0].icon).substr(0, 2); // "10d" → "10"
```

`substr(0, 2)` = 0번 인덱스부터 **2글자 전**까지 → 앞 두 글자.

| 코드 | Font Awesome | 느낌 |
|------|--------------|------|
| `01` | `fas fa-sun` | 맑음 |
| `02` | `fas fa-cloud-sun` | 구름 조금 |
| `03` | `fas fa-cloud` | 구름 |
| `04` | `fas fa-cloud-meatball` | 흐림 |
| `09` | `fas fa-cloud-sun-rain` | 소나기 |
| `10` | `fas fa-cloud-showers-heavy` | 비 |
| `11` | `fas fa-poo-storm` | 뇌우 |
| `13` | `fas fa-snowflake` | 눈 |
| `50` | `fas fa-smog` | 안개 |

객체로 매핑합니다.

```javascript
let weatherIcon = {
    '01': 'fas fa-sun',
    '02': 'fas fa-cloud-sun',
    '03': 'fas fa-cloud',
    '04': 'fas fa-cloud-meatball',
    '09': 'fas fa-cloud-sun-rain',
    '10': 'fas fa-cloud-showers-heavy',
    '11': 'fas fa-poo-storm',
    '13': 'fas fa-snowflake',
    '50': 'fas fa-smog'
};

$('.currIcon').append(`<i class="${weatherIcon[$Icon]}"></i>`);
$('.currTemp').prepend(Math.floor(data.main.temp) + '℃');
$('.city').append(data.name);
```

`Math.floor`는 소수점 아래를 버립니다. `24.67` → `24℃`.

`prepend`를 쓰는 이유: HTML이 `<div class="currTemp"></div>`라서, 온도를 **앞(안)** 에 넣습니다. `city`는 `"도시 : "` 뒤에 이름을 `append`합니다.

### 5-2. 레이아웃 (float)

```css
.weather {
    width: 300px;
    height: 150px;
    text-align: center;
    background-color: cornflowerblue;
    color: #fff;
}
.weather > div {
    float: left;
    height: 75px;
    line-height: 75px;
    width: 50%;
}
.weather > div.currIcon,
.weather > div.currTemp { font-size: 50px; }
.weather > div.city { width: 100%; font-size: 23px; }
```

한 줄에 아이콘·온도 50%씩, 다음 줄에 도시명 100%입니다. `line-height`와 `height`를 같게 해서 세로 가운데처럼 보이게 합니다.

Font Awesome은 `<head>`에서 불러 옵니다.

```html
<script defer src="https://use.fontawesome.com/releases/v5.15.2/js/all.js" ...></script>
```

`$(function(){ ... })`는 **문서가 준비된 뒤** 실행입니다. 선택자 `.currIcon`이 HTML에 생긴 다음에 AJAX를 돌리기 위함입니다.

## 6. weather_fetch1 — jQuery 없이 fetch

같은 API를 **바닐라 JS**로 요청합니다.

```javascript
fetch(apiURI)
  .then(response => response.json())
  .then(resp => {
      document.querySelector('.ctemp').innerHTML =
          "현재 온도 : " + resp.main.temp + "℃";
      document.querySelector('.clowtemp').innerHTML =
          "최저 온도 : " + resp.main.temp_min + "℃";
      document.querySelector('.chightemp').innerHTML =
          "최고 온도 : " + resp.main.temp_max + "℃";
      document.querySelector('.cicon').innerHTML =
          '아이콘 : <i class="' + weatherIcon[resp.weather[0].icon.substr(0, 2)] + '"></i>';
  })
  .catch(error => console.error('에러 발생:', error));
```

동작 순서

```
fetch(주소)
    │
    ▼
1번째 then  → 응답 본문을 JSON으로 변환 (response.json())
    │
    ▼
2번째 then  → 변환된 객체(resp)로 화면 채우기
    │
    ▼
catch      → 네트워크/파싱 실패 시 콘솔
```

| jQuery | fetch |
|--------|--------|
| `$.getJSON` / `$.ajax` | `fetch` + `.json()` |
| `$('.ctemp').append(...)` | `querySelector('.ctemp').innerHTML = ...` |
| `success` / `error` | `then` / `catch` |

`weather_fetch1.html`에는 ajax 위젯용 CSS(`.weather`)가 남아 있지만, 실제 출력은 `weather1`과 같은 `.ctemp` 구조입니다. 아이콘만 Font Awesome으로 바뀐 버전입니다.

스크립트가 `</body>` **아래**에 있어서, 실행 시점에 HTML 요소가 이미 있습니다. `$(function(){})`가 없어도 됩니다.

---

## 7. 요청 방법 비교

| | `$.getJSON` | `$.ajax` | `fetch` |
|--|-------------|----------|---------|
| 파일 | weather1, weather2 | weather_ajax, ajax1 | weather_fetch1 |
| 라이브러리 | jQuery | jQuery | 없음 (브라우저 내장) |
| 성공 | 콜백 함수 하나 | `success` | `.then` |
| 실패 | 기본은 조용함 | `error` | `.catch` |
| JSON 변환 | 자동 | `dataType: "json"` | `response.json()` |

세 방법 모두 **비동기**입니다. 요청을 보내 놓고 다른 코드를 먼저 실행하고, 데이터가 오면 콜백/`then`이 실행됩니다. (`async: false`만 예외)

---

## 8. DOM에 넣는 방법

| 메서드 | 위치 | 예 |
|--------|------|-----|
| `append` | 기존 내용 **뒤** | `"현재 온도: "` + `24.5` |
| `prepend` | 기존 내용 **앞** | 날짜 + `" \| 날씨예보"` |
| `innerHTML =` | **통째로 교체** | `"현재 온도 : 24.5℃"` |

`append`는 새로고침 없이 여러 번 호출하면 숫자가 계속 붙습니다. `innerHTML =`는 매번 덮어씁니다.

## 9. 0831~0909에서 이어지는 점

스크롤·메뉴는 **이미 있는 HTML을 언제 움직이게 할지**였고, 오늘은 **서버 JSON을 언제 받아서 넣을지**입니다.

```
클릭/스크롤 이벤트
  → 콜백에서 class / animate

API 요청
  → 콜백(then)에서 temp / icon을 DOM에 넣기
```

둘 다 **나중에 실행되는 함수**가 핵심입니다.
