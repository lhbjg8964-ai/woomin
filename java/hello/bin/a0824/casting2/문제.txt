[문제] 차량 대여 시스템 (casting1과 같은 패턴)

casting1 직원 관리와 같은 방식으로 아래를 구현하세요.

1. 추상 부모 클래스 Vehicle
   - 필드: name(차종명), id, baseFee(기본요금)
   - 생성자로 세 값을 초기화
   - 추상 메서드: double calculateFee()  // 차종마다 요금 계산이 다름
   - 공통 메서드 printInfo(): ID, 이름, 기본요금, 실요금 출력
   - getName()

2. 자식 클래스 3개 (각각 calculateFee 오버라이드 + 자기만의 메서드)

   (1) Sedan : 보험료 insurance
       요금 = 기본요금 + 보험료
       driveSedan() → "홍길동(세단)이(가) 세단을 운행합니다." 처럼 출력

   (2) Truck : 운행시간 workHours, 시간당요금 hourlyRate
       요금 = 기본요금 + (운행시간 * 시간당요금)
       haulCargo() → 운행시간 안내 출력

   (3) ElectricCar : 배터리관리비 batteryCare, 좌석수 seats
       요금 = 기본요금 + 배터리관리비 + 좌석수
       chargeBattery() → 좌석 수와 함께 충전 안내 출력

3. Main1에서 할 일
   - Vehicle 배열(크기 5)에 자식 객체를 업캐스팅해서 담기
     [0] Sedan "아반떼", 1, 50000, 보험 20000
     [1] Truck "포터", 2, 0, 8시간, 시간당 15000
     [2] ElectricCar "아이오닉", 3, 80000, 배터리관리 10000, 좌석 5
     [3] Sedan "소나타", 4, 60000, 보험 25000
     [4] Truck "마이티", 5, 0, 6시간, 시간당 18000
   - 모든 차량 printInfo() 호출 (다형성)
   - 전체 요금 합계 출력
   - instanceof + 다운캐스팅으로 타입별 전용 메서드 호출
   - 이름 "아반떼" 검색 후 정보 출력 (없으면 못 찾았다고 출력)
