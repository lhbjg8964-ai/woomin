## 2. for문 + 배열

### 문제 2-1 (출력 결과 예측)
다음 코드의 출력 결과를 적으세요.

```java
int[] arr = {10, 20, 30, 40};
int sum = 0;

for (int i = 0; i < arr.length; i++) {
    sum += arr[i];
}

System.out.println(sum);
```

### 문제 2-2 (코드 작성)
`{85, 90, 78, 92, 88}` 배열의 **최대값**을 찾아 출력하는 프로그램을 작성하세요.

> 힌트: `max` 변수를 0으로 초기화하고, for문으로 하나씩 비교한다.

### 문제 2-3 (객관식)
향상 for문의 올바른 형식은?

1. `for (int i = 0; i < arr.length; i++)`
2. `for (int x : arr)`
3. `for (arr : int x)`
4. `for each (int x in arr)`
