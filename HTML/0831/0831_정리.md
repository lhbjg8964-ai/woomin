## 1. 가로 아코디언 (Width 방식)

세로로 접히는 일반 아코디언과 달리, **탭은 세로 막대(`dt`)**, **내용은 가로로 펼쳐지는 패널(`dd`)** 입니다.

### 1-1. HTML 뼈대

```html
<dl>
  <dt id="step1"><span>Step.1</span></dt>
  <dd><p>내용 1</p></dd>
  <dt id="step2"><span>Step.2</span></dt>
  <dd><p>내용 2</p></dd>
  <dt id="step3"><span>Step.3</span></dt>
  <dd><p>내용 3</p></dd>
</dl>
```

- `dt` 너비 35px × 3개 = 105px
- 열린 `dd` 너비 695px
- 합이 800px → 바깥 `div` 너비와 맞춤

`span`의 `text-indent: -9999px`는 글자를 화면 밖으로 밀어 **이미지 탭만 보이게** 하는 기법입니다.

### 1-2. 배경 이미지 3단계

| 상태 | 클래스 | 이미지 |
|------|--------|--------|
| 기본 | 없음 | `background-1.jpg` |
| 마우스 오버 | `.over` | `background-1-over.jpg` |
| 선택된(열린) | `.selected` | `background-1-selected.jpg` |

### 1-3. 세 파일 비교

| 파일 | 방식 | 애니메이션 | 특징 |
|------|------|------------|------|
| `accodion2/index.html` | 바닐라 JS, `style.width` 직접 변경 | CSS `transition: all 0.4s` | for 루프, `nextElementSibling` |
| `아코디언2jq/index1.html` | jQuery `animate({ width })` | JS가 너비를 0.5초에 걸쳐 변경 | hover 시 `.over`, 이미 열린 탭은 무시 |
| `아코디언2jq/index_va.html` | 클래스 `.active` / `.selected` | CSS `transition: width 0.5s` | flex 레이아웃, hover는 CSS `:hover` |

실무에서는 **클래스 + CSS transition** (`index_va.html`)이 가장 깔끔합니다. JS는 “어느 패널을 켤지”만 결정합니다.

### 1-4. 바닐라 JS 흐름 (`accodion2/index.html`)

```javascript
document.addEventListener('DOMContentLoaded', function () {
    var ddList = document.querySelectorAll('dd');
    var dtList = document.querySelectorAll('dl dt');
    var dtListSpan = document.querySelectorAll('dl dt span');

    // 첫 번째만 열고 나머지 닫기
    for (var i = 1; i < ddList.length; i++) {
        ddList[i].style.width = '0px';
    }
    dtListSpan[0].classList.add('selected');

    for (var i = 0; i < dtList.length; i++) {
        dtList[i].addEventListener('click', function () {
            var nextDD = this.nextElementSibling; // 클릭한 dt 바로 다음 dd

            if (nextDD.style.width == '0px' || nextDD.style.width === '') {
                for (var j = 0; j < ddList.length; j++) {
                    ddList[j].style.width = '0px';
                }
            }
            nextDD.style.width = '695px';

            for (var k = 0; k < dtList.length; k++) {
                dtListSpan[k].classList.remove('selected');
            }
            this.querySelector('span').classList.add('selected');
        });
    }
});
```

원본 85행에 `nextDd`(대소문자 다름)가 있습니다. 조건이 제대로 안 먹을 수 있으니 **`nextDD`로 통일**해야 합니다.

### 1-5. jQuery 버전 핵심 (`index1.html`)

```javascript
$("dd").css("width", "0px");
$("dd").eq(0).css("width", "695px");
$("dt:eq(0) span").addClass("selected");

$("dl dt").click(function () {
    if ($(this).next("dd").css("width") == "0px") {
        $("dt:has(.selected)").next("dd").animate({ width: "0px" }, 500);
        $(this).next("dd").animate({ width: "695px" }, 500);
        $("dt span").removeClass("selected");
        $(this).find("span").addClass("selected");
    }
});
```

- `$("dt:has(.selected)")` — `.selected`를 **자손으로 가진 dt**만 고름
- 이미 열린 탭을 다시 눌러도 `width == "0px"`가 아니므로 **아무 일도 안 함**
- hover는 `addClass('over')` / `removeClass('over')` 두 함수

### 1-6. 클래스 방식 (`index_va.html`)

```css
dd { width: 0; transition: width 0.5s ease; }
dd.active { width: 695px; }
```

```javascript
dts.forEach((dt, index) => {
    dt.addEventListener('click', () => {
        if (dds[index].classList.contains('active')) return;
        dds.forEach(dd => dd.classList.remove('active'));
        spans.forEach(span => span.classList.remove('selected'));
        dds[index].classList.add('active');
        dt.querySelector('span').classList.add('selected');
    });
});
```

`nextElementSibling` 대신 **같은 인덱스**로 `dt`와 `dd`를 짝짓습니다. `float` 대신 `display: flex`를 쓰면 레이아웃이 더 안정적입니다.

## 2. 스크롤 애니메이션

핵심 흐름은 항상 같습니다.

1. CSS로 요소를 화면 밖 또는 투명하게 숨긴다.
2. `$(window).scroll()`에서 `scrollTop`을 읽는다.
3. 조건이 맞으면 `animate()` 또는 `addClass`로 보이게 한다.

### 2-1. 파일별 역할

| 파일 | 무엇을 배우나 |
|------|----------------|
| `offset.html` | `.offset().top` / `.offset().left` 콘솔 확인 |
| `scroll1.html` | `left: -150px`에 숨긴 박스를 `animate({ left: '50%' })` |
| `scroll2.html` | `opacity: 0 → 1` 페이드 인 |
| `scroll3.html` | `100vh` 섹션 + 좌우 카드 + `setTimeout` 순차 등장 |
| `scroll4.html` | 고정 메뉴, 현재 섹션 표시, 메뉴 클릭 시 스크롤 이동 |

### 2-2. offset — 조건 잡기 전 숫자 확인

```javascript
let abox = $('.box1').offset().top;   // 문서 맨 위에서 몇 px
let cbox = $('.box3').offset().left;  // 문서 맨 왼쪽에서 몇 px
console.log(abox, cbox);
```

이후 `if (sct >= 450)` 같은 숫자를 감으로 쓰지 않고, **실제 위치**를 보고 정합니다.

### 2-3. scroll1 — animate vs 클래스

```javascript
$(window).scroll(function () {
    var sct = $(window).scrollTop();
    $('.sTop').text(sct);

    if (sct >= 10)   $('.box1').stop().animate({ left: '50%' }, 800);
    if (sct >= 500)  $('.box2').stop().animate({ left: '50%' }, 800);
    if (sct >= 1200) $('.box3').stop().animate({ right: '50%' }, 800);

    if (sct <= 1500) $('.box4').removeClass('on');
    if (sct >= 2000) $('.box4').addClass('on');
});
```

- `.stop()` — 스크롤을 빠르게 내릴 때 애니메이션이 큐에 쌓이지 않게 함
- box1~3: JS `animate()`
- box4: `.on` + CSS `transition: right 0.3s`

### 2-4. scroll2 — 페이드 인

위치(`left`)가 아니라 **투명도**만 바꿉니다.

```css
.container > div > img { opacity: 0; transition: all 0.8s; }
.container > div.on > img { opacity: 1; margin-top: 20px; }
```

### 2-5. scroll3 — 구간에만 등장, 지나면 다시 숨김

```javascript
if (sct >= 450 && sct <= 1000) {
    $('.left1').addClass('on');
} else {
    $('.left1').removeClass('on');
}
```

`&&`로 구간을 묶었기 때문에 **해당 섹션을 벗어나면 카드가 다시 화면 밖으로 나갑니다.** 스크롤을 올려도 애니메이션이 반복됩니다.

section4의 네 카드는 `setTimeout`으로 0.4초 간격 순차 등장입니다.

```javascript
if (sct >= 2500) {
    $('.s4_1').addClass('active');
    setTimeout(function () { $('.s4_2').addClass('active'); }, 400);
    setTimeout(function () { $('.s4_3').addClass('active'); }, 800);
    setTimeout(function () { $('.s4_4').addClass('active'); }, 1200);
}
```

원본 `scroll3.js`의 `$('s_Top')`는 점(`.`)이 빠져 있습니다. 스크롤 숫자가 안 보이면 **`$('.s_Top')`** 로 고칩니다.

### 2-6. scroll4 — 고정 메뉴 + 클릭 이동

`scroll3`에 내비게이션을 붙인 완성본입니다.

```css
nav { position: absolute; background: rgba(255,255,255,0.5); }
nav.fixed { position: fixed; background: rgba(255,255,255,1); }
body { overflow-x: hidden; } /* left: -350px 때문에 가로 스크롤이 생기는 것 방지 */
```

```javascript
// 100px 이상이면 메뉴 고정
if (sct >= 100) $('nav').addClass('fixed');
else $('nav').removeClass('fixed');

// 현재 보고 있는 섹션에 메뉴 .on
if (sct >= $('.container > div').eq(0).offset().top) {
    $('nav ul li').removeClass('on');
    $('nav ul li').eq(0).addClass('on');
}

// 메뉴 클릭 → 해당 섹션으로 부드럽게 이동
$('nav ul li').click(function () {
    var i = $(this).index();
    var offset_t = $('.container > div').eq(i).offset().top;
    $('html, body').stop().animate({ scrollTop: offset_t }, 1000);
    return false; // a 태그 기본 점프 막기
});
```

메뉴 `.on`은 클릭 시점이 아니라 **스크롤 이벤트 안**에서 바꿉니다. 휠로 내려가도 현재 섹션이 주황색으로 표시됩니다.

## 3. 움직이는 방법 비교

| | jQuery `animate()` | 클래스 + CSS `transition` |
|--|--------------------|---------------------------|
| 예제 | scroll1, 아코디언 index1 | scroll3/4, 아코디언 index_va |
| 위치 변경 | JS `{ left: '50%' }` | CSS `.on { left: 100px }` |
| 되돌리기 | 다시 `animate` | `removeClass('on')` |
| 권장 | 한 번만 등장할 때 | 반복 등장, 유지보수 |
