## 파일별 설명

### 1) 상자 배치 (핵심)

| 파일 | 설명 |
|------|------|
| `애국가.html` | `bigbox` 안에 `box` 4개, **한 줄 2개** |
| `커피.html` | 커피 주제 `box` 6개, **한 줄 3개** (너비 680px) |

**포인트**
- `float: left` → 상자 가로 나열
- `margin: 0 auto` → 큰 상자 가운데 정렬
- 한 줄에 넣는 개수에 맞게 `bigbox` **width** 조절

### 2) overflow

| 파일 | 설명 |
|------|------|
| `애국가_overflow.html` | `scroll`, `auto`, `hidden` 등 overflow 연습 |
| `애국가_overflow_height.html` | 높이 + overflow 연습 |

**포인트**
- `overflow: hidden` → 넘치는 내용 숨김
- `overflow: scroll` → 항상 스크롤
- `overflow: auto` → 필요할 때만 스크롤
- `overflow-x: hidden` → 가로 스크롤 방지

### 3) 페이지 레이아웃

| 파일 | 설명 |
|------|------|
| `layout.html` + `css/layout.css` | header / sidebar / section / footer |
| `layout2.html` + `css/layout2.css` | 레이아웃 변형 |

**포인트**
- sidebar, section → `float: left`
- footer → `clear: left` (float 해제)

### 4) CSS 기초 연습

| 파일 | 주제 |
|------|------|
| `box1.html` ~ `box4.html` | 상자(box) 만들기 |
| `border1.html`, `border2.html` | 테두리 |
| `border-radius.html` | 둥근 모서리 |

## 오늘 핵심 코드

### 큰 상자 + 작은 상자
```css
.bigbox {
    width: 450px;          /* 3열이면 680px 정도 */
    height: 500px;
    border: 3px double #000;
    margin-left: auto;
    margin-right: auto;
}
.box {
    width: 200px;
    height: 200px;
    border: 1px solid #000;
    float: left;
    margin-left: 9px;
    margin-bottom: 7px;
}
```

### 레이아웃 float 해제
```css
#footer {
    clear: left;   /* 위쪽 float 영향 끊기 */
}
```
