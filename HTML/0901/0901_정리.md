## 오늘 핵심 한 줄

| 주제 | 핵심 |
|------|------|
| 한 화면 스크롤 | `.mousewheel`에서 `d > 0`이면 이전 섹션, `d < 0`이면 다음 섹션 |
| easing | `animate(..., 1000, 'easeOutBounce')` — 튕기듯 도착 |
| 고정 메뉴 | `scrollTop > 50`이면 `nav`에 `.fixed` |
| 현재 메뉴 | 각 섹션 `offset().top`과 `sct` 비교 후 `li`에 `.on` |

| 쿠키 팝업 | `$.cookie('이름', '값', { expires: 일수 })` |

## 1. scroll4 — 전날 예제 + 휠 한 화면 이동

HTML은 0831 `scroll4.html`과 같고, 스크립트만 두 개가 더 붙습니다.

```html
<script src="js/jquery.mousewheel.min.js"></script>
<script src="js/jquery.easing.1.3.js"></script>
<script src="js/scroll4.js"></script>
```

### 1-1. 전날과 같은 부분

- 스크롤 구간에 `.left1` / `.right1` 등장
- `sct >= 2500`이면 section4 카드 순차 `active`
- `sct >= 100`이면 `nav.fixed`
- 메뉴 클릭 → `animate({ scrollTop: 해당섹션 })`

### 1-2. 새로 넣은 마우스 휠

```javascript
$('.section').mousewheel(function (event, d) {
    // d > 0 : 휠을 위로 (이전 섹션)
    // d < 0 : 휠을 아래로 (다음 섹션)
    if (d > 0) {
        let preVal = $(this).prev().offset().top;
        $('html, body').stop().animate({ scrollTop: preVal }, 1000, 'easeOutBounce');
    }
    if (d < 0) {
        let nextVal = $(this).next().offset().top;
        $('html, body').stop().animate({ scrollTop: nextVal }, 1000, 'easeOutBounce');
    }
});
```

동작

1. 휠 이벤트가 **현재 `.section`** 에서 발생한다.
2. `$(this).prev()` / `$(this).next()`로 이웃 섹션의 `offset().top`을 구한다.
3. `html, body`의 `scrollTop`을 그 위치로 1초에 걸쳐 이동한다.
4. `'easeOutBounce'`는 easing 플러그인이 제공하는 **끝에 한 번 튕기는** 곡선이다.

첫 섹션에서 휠을 올리거나 마지막 섹션에서 휠을 내리면 `prev()`/`next()`가 없어 `offset()`이 에러 날 수 있습니다. 필요하면 존재 여부를 먼저 검사합니다.

```javascript
if (d > 0 && $(this).prev().length) { /* ... */ }
if (d < 0 && $(this).next().length) { /* ... */ }
```

`scroll4.js`의 `$('s_Top')`도 0831과 같이 점이 빠져 있습니다. 숫자를 보려면 `$('.s_Top')`으로 고칩니다.

## 2. rescroll1 — 원페이지 + 플로팅 + 팝업

한 페이지에 아래가 모두 들어 있습니다.

- 5개 풀스크린 섹션 (`#section1` ~ `#section5`)
- 상단 메뉴 고정 / 현재 섹션 강조
- 오른쪽 동그라미 플로팅 메뉴
- 이미지맵 팝업 + “오늘 하루 열지 않음”
- 공지 팝업 + “3일 동안 이 창 열지 않기”
- jQuery UI `draggable()`로 팝업을 마우스로 끌기

관련 파일: `rescroll1.html`, `js/main.js`

### 2-1. 섹션 위치 미리 재기

```javascript
var off_1 = $('#section1').offset().top;
var of_1  = $('#wrap > section').eq(0).offset().top; // 같은 값, 다른 선택자
```

id로 고르든 `eq(인덱스)`로 고르든 **결과는 같습니다.** 메뉴 클릭·현재 메뉴 표시는 `eq(i)`가 반복에 유리합니다.

### 2-2. 고정 메뉴 + 현재 섹션

```javascript
$(window).scroll(function () {
    var sct = $(window).scrollTop();
    $('.s_Top').text(sct);

    if (sct > 50) $('nav').addClass('fixed');
    else $('nav').removeClass('fixed');

    if (sct >= $('#wrap > section').eq(0).offset().top) {
        $('nav ul li').removeClass('on');
        $('nav ul li').eq(0).addClass('on');
    }
    // eq(1) ~ eq(4) 동일
});
```

CSS

```css
nav { position: absolute; top: 50px; background: rgba(255,255,255,0.5); }
nav.fixed { position: fixed; top: 0; background: rgba(255,255,255,1); }
nav ul li.on a { color: orange; }
```

처음에는 배경 위에 살짝 떠 있다가, 조금 내리면 **화면 맨 위에 고정**되고 배경이 불투명해집니다.

메뉴 클릭 이동

```javascript
$('nav ul li').click(function () {
    var i = $(this).index();
    var off_top = $('#wrap > section').eq(i).offset().top;
    $('html, body').stop().animate({ scrollTop: off_top + 'px' }, 800);
    return false;
});
```

`return false`는 `<a href="#">`의 기본 동작(맨 위로 점프)을 막습니다.

### 2-3. 플로팅 메뉴 — 스크롤을 따라가는 상자

```css
#float_div {
    position: absolute; /* fixed가 아님 */
    right: 50px;
    top: 250px;
}
#float_div ul li.on { background-color: orange; }
```

```javascript
var f_top = $('#float_div').offset().top; // 처음 위치 250

$(window).scroll(function () {
    var sct = $(window).scrollTop();
    $('#float_div').stop().animate({ top: f_top + sct }, 300);
});
```

`position: absolute`의 `top`은 **문서 기준**입니다. 스크롤한 만큼(`sct`)을 더해 주면, 화면에서 항상 비슷한 높이에 있는 것처럼 보입니다. `fixed`를 쓰지 않고 **부드럽게 따라오게** 하는  klasik한 기법입니다.

### 2-4. 팝업을 드래그로 옮기기

```javascript
$('#popup').draggable();
$('#notice_wrap').draggable();
```

`jquery-ui.js`의 `draggable()`입니다. 팝업 `position: absolute`가 있어야 마우스로 위치를 바꿀 수 있습니다.

### 2-5. 이미지맵 팝업 + 오늘 하루 닫기

HTML

```html
<div id="popup">
    <img src="images/popup.jpg" usemap="#pop">
    <map name="pop" id="pop">
        <area shape="rect" coords="253,330,293,344" href="#" alt="창닫기">
        <area shape="rect" coords="93,329,217,344" href="#" alt="오늘하루 열지않음">
    </map>
</div>
```

`usemap`은 **그림 한 장에 여러 클릭 영역**을 만드는 태그입니다. `coords`는 이미지 픽셀 좌표입니다.

쿠키 로직 (`js/main.js`)

```javascript
// 쿠키 pop 이 'no'가 아니면 보여 주기 (첫 방문 포함)
if ($.cookie('pop') != 'no') {
    $('#popup').show();
}

// 창닫기만 — 쿠키 없음, 새로고침하면 다시 보임
$('#popup area:eq(0)').click(function () {
    $('#popup').fadeOut('fast');
});

// 오늘 하루 열지 않음 — 1일짜리 쿠키
$('#popup area:eq(1)').click(function () {
    $.cookie('pop', 'no', { expires: 1 });
    $('#popup').fadeOut('fast');
});
```

| 버튼 | 쿠키 | 다시 보이는 시점 |
|------|------|------------------|
| 창닫기 | 없음 | 새로고침하면 즉시 |
| 오늘 하루 열지 않음 | `pop=no`, 1일 | 내일(만료 후) |

### 2-6. 공지 팝업 + 3일 닫기

```javascript
$('#notice_wrap').draggable();

if ($.cookie('popup') == 'none') {
    $('#notice_wrap').hide();
}

var chk = $('#expiresChk');
$('.closeBtn').on('click', closePop);

function closePop() {
    if (chk.is(':checked')) {
        $.cookie('popup', 'none', { expires: 3 });
    }
    $('#notice_wrap').fadeOut();
}
```

체크박스를 켠 채로 닫기 → 쿠키 `popup=none`을 **3일** 저장 → 그 기간에는 공지가 안 나옵니다. 체크 없이 닫으면 새로고침 때 다시 보입니다.

두 팝업의 쿠키 **이름**이 다릅니다 (`pop` / `popup`). 서로 간섭하지 않습니다.

## 3. jquery.cookie 사용법

```javascript
$.cookie('이름', '값', { expires: 일수 }); // 저장
$.cookie('이름');                          // 읽기 (없으면 undefined)
```

| 예제 | 이름 | 값 | 기간 |
|------|------|-----|------|
| 이미지맵 팝업 | `pop` | `no` | 1일 |
| 공지 팝업 | `popup` | `none` | 3일 |

브라우저 개발자 도구 → Application(또는 저장소) → Cookies 에서 확인할 수 있습니다.

```
offset (위치 숫자)
  → scroll1 (박스가 옆에서 들어옴)
    → scroll2 (페이드 인)
      → scroll3 (섹션 카드 + 순차 등장)
        → scroll4 0831 (고정 메뉴 + 클릭 이동)
          → scroll4 0901 (마우스휠 한 화면 + easing)
            → rescroll1 (플로팅 메뉴 + 쿠키 팝업 + 드래그)
```

## 6. CSS 포인트 (`rescroll1.html`)

```css
section { width: 100%; height: 100vh; }          /* 한 화면 = 한 섹션 */
#section1 { background: url(img/b1.jpg) 50% 50% / cover; }

nav ul { display: flex; width: 1000px; margin: 0 auto; }
nav ul li a {
    display: block;
    width: 200px;
    height: 50px;
    line-height: 50px;   /* height와 같으면 세로 가운데 */
    text-align: center;
}

.s_Top { position: fixed; } /* fixed/absolute면 인라인처럼 줄어듦 */
```

배경 단축: `url(...) 50% 50% / cover` 는 `background-position`과 `background-size`를 한 줄에 쓴 것입니다.
