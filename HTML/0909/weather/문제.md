# Weather API 연습 문제 (0909)

왼쪽 `weather` 폴더 예제(`weather1` ~ `weather_fetch1`)를 보고 푸세요.

정답: [정답.md](./정답.md)

---

## 공통 코드 (1~10번 기준)

`weather2.html` / `weather_ajax.html` 에서 쓰는 현재 날씨 URL입니다.

```javascript
var url = 'https://api.openweathermap.org/data/2.5/weather?id=1835848&appid=키&units=metric';
```

현재 날씨 JSON(일부) 예시:

```json
{
  "weather": [
    { "id": 500, "main": "Rain", "description": "light rain", "icon": "10d" }
  ],
  "main": {
    "temp": 24.67,
    "temp_min": 22.1,
    "temp_max": 26.4,
    "humidity": 78
  },
  "wind": { "speed": 3.2 },
  "clouds": { "all": 75 },
  "sys": { "country": "KR" },
  "name": "Seoul"
}
```

예보 API(`forecast`)는 `list` 배열이 있고, 예제는 `list[0]`만 사용합니다.

# 6단계: 오류 찾기

각 코드에서 **잘못된 부분**을 찾고 고치세요.

### 6-1. 현재 날씨인데 예보처럼 읽음

```javascript
// URL: /data/2.5/weather
$.getJSON(url, function(result){
    let $ctemp = result.list[0].main.temp;
});
```

### 6-2. 아이콘 매핑이 undefined

```javascript
let weatherIcon = { '10': 'fas fa-cloud-showers-heavy' };
let icon = data.weather[0].icon; // "10d"
$('.currIcon').append('<i class="' + weatherIcon[icon] + '"></i>');
```

### 6-3. 월이 한 달 작게 나옴

```javascript
let $now = new Date(); // 오늘은 2026-09-09
let $cDate = $now.getFullYear() + '-' + $now.getMonth() + '-' + $now.getDate();
```

### 6-4. fetch JSON을 안 바꿈

```javascript
fetch(apiURI)
  .then(response => {
      document.querySelector('.ctemp').innerHTML = response.main.temp;
  });
```

### 6-5. 선택자

```javascript
// HTML: <div class="clowtemp">최저 온도: </div>

```
