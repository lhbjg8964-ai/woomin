## 6단계: 오류 찾기

### 6-1

현재 날씨(`/weather`)에는 `list`가 없습니다.

```javascript
let $ctemp = result.main.temp;
```

예보(`/forecast`)를 쓸 때만 `result.list[0].main.temp`입니다.

### 6-2

`"10d"` 전체를 키로 쓰면 `weatherIcon["10d"]` → `undefined`.

```javascript
let icon = data.weather[0].icon.substr(0, 2); // "10"
$('.currIcon').append('<i class="' + weatherIcon[icon] + '"></i>');
```

### 6-3

`getMonth()`가 8을 주므로 `2026-8-9`가 됩니다. (9월인데 8)

```javascript
let $cDate = $now.getFullYear() + '-' + ($now.getMonth() + 1) + '-' + $now.getDate();
```

### 6-4

첫 `then`의 `response`는 JSON이 아니라 **Response 객체**입니다. `.json()`이 필요합니다.

```javascript
fetch(apiURI)
  .then(response => response.json())
  .then(resp => {
      document.querySelector('.ctemp').innerHTML = resp.main.temp;
  });
```

### 6-5

클래스 선택자는 점(`.`)이 필요합니다.

```javascript
$('.clowtemp').append($mintemp);
```

`$('clowtemp')`는 `<clowtemp>` 태그로 찾습니다.

## 7단계: 서술형 예시

### 1. 세 방법 비교

공통점: 모두 서버에 GET으로 JSON을 요청하고, **데이터가 도착한 뒤** 콜백/`then`에서 DOM을 채웁니다.

| | `$.getJSON` | `$.ajax` | `fetch` |
|--|-------------|----------|---------|
| 라이브러리 | jQuery | jQuery | 없음 |
| 성공 | 두 번째 인자 함수 | `success` | `.then` |
| 실패 | 잘 안 보임 | `error` | `.catch` |
| JSON | 자동 | `dataType: "json"` | `response.json()` |

수업 순서: 짧게(`getJSON`) → 옵션 명시(`ajax`) → 라이브러리 없이(`fetch`).

### 2. 왜 `weather[0]`인가

응답의 `weather`가 **배열**이기 때문입니다. 날씨 상태가 여러 개일 수 있어, 보통 대표값 한 개만 `[0]`으로 꺼냅니다. `weather.icon`은 오류입니다.

### 3. append vs innerHTML

- `append`: 이미 있는 `"현재 온도: "` **뒤에** `24.67`만 이어 붙임 (`weather1`, `weather2`)
- `innerHTML =`: 요소 안을 `"현재 온도 : 24.67℃"`로 **통째로 교체** (`weather_fetch1`)

`append`를 같은 요소에 두 번 하면 숫자가 두 번 붙습니다. `innerHTML =`는 덮어씁니다.

### 4. weather1 vs weather2

| | weather1 | weather2 |
|--|----------|----------|
| URL | `/forecast` | `/weather` |
| 온도 | `list[0].main.temp` | `main.temp` |
| 아이콘 | `list[0].weather[0].icon` | `weather[0].icon` |
| 날짜 | API `dt_txt` | `new Date()` |
| 요청 | `$.getJSON` | `$.getJSON` |

## 8단계: 실습 정답 예시

URL의 `appid`는 수업 파일과 같은 키를 쓰면 됩니다.

### 실습 1 — 콘솔

```javascript
$.ajax({
    url: apiURI,
    type: "GET",
    dataType: "json",
    success: function (resp) {
        console.log("현재 온도 " + resp.main.temp);
        console.log("최저 온도 " + resp.main.temp_min);
        console.log("최고 온도 " + resp.main.temp_max);
        console.log("습도 " + resp.main.humidity);
        console.log("아이콘 " + resp.weather[0].icon);
        console.log("도시명 " + resp.name);
    }
});
```

### 실습 2 — getJSON 화면

`weather2.html`과 동일 구조입니다. 핵심만:

```javascript
$.getJSON(url, function (result) {
    $(".ctemp").append(result.main.temp);
    $('.clowtemp').append(result.main.temp_min);
    $('.chightemp').append(result.main.temp_max);
    $('.cicon').append(
        `<img src=https://openweathermap.org/img/wn/${result.weather[0].icon}@2x.png>`
    );
    let n = new Date();
    $('h2').prepend(n.getFullYear() + '-' + (n.getMonth() + 1) + '-' + n.getDate());
});
```

### 실습 3 — 위젯

`weather_ajax.html`을 그대로 따라 가면 됩니다.

```javascript
let $Icon = data.weather[0].icon.substr(0, 2);
$('.currIcon').append(`<i class="${weatherIcon[$Icon]}"></i>`);
$('.currTemp').prepend(Math.floor(data.main.temp) + '℃');
$('.city').append(data.name);
```

### 실습 4 — fetch

`weather_fetch1.html` 참고. jQuery `<script>`는 넣지 않습니다.

```javascript
fetch(apiURI)
  .then(r => r.json())
  .then(resp => {
      document.querySelector('.ctemp').innerHTML = "현재 온도 : " + resp.main.temp + "℃";
      document.querySelector('.clowtemp').innerHTML = "최저 온도 : " + resp.main.temp_min + "℃";
      document.querySelector('.chightemp').innerHTML = "최고 온도 : " + resp.main.temp_max + "℃";
  })
  .catch(err => console.error(err));
```

### 실습 5 — 예보 3칸

URL은 **forecast** 여야 합니다.

```javascript
$.getJSON(url, function (result) {
    for (let i = 0; i < 3; i++) {
        let item = result.list[i];
        $('body').append(
            `<p>${item.dt_txt} / ${item.main.temp}℃</p>`
        );
    }
});
```

`list[0]`만 쓰면 실습 5가 아닙니다. 인덱스 0, 1, 2를 모두 써야 합니다.

### 실습 6 — 습도

HTML에 한 줄 추가:

```html
<div class="chumidity">현재 습도: </div>
```

```javascript
document.querySelector('.chumidity').innerHTML =
```
