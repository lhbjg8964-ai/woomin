카드 레이아웃 비교

이미지 + 글자 카드 3개를 Float / Flex / Grid로 각각 배치했습니다.

1. Float

카드에 float: left를 주고, 부모에 clearfix 처리합니다.

산 여행

맑은 공기와 함께하는 산속 힐링 코스입니다.

도시 탐방

밤낮으로 빛나는 도심의 매력을 만나보세요.

호수 산책

잔잔한 물결 옆에서 여유로운 하루를 보냅니다.

2. Flex

부모에 display: flex와 gap을 사용해 가로로 배치합니다.

반려견

함께하는 일상이 더 특별해지는 순간입니다.

고양이

귀엽고 도도한 매력의 반려묘를 소개합니다.

야생동물

자연 속 강인한 생명력을 느껴보세요.

3. Grid

부모에 display: grid와 grid-template-columns: repeat(3, 1fr)을 사용합니다.

커피

향긋한 원두로 시작하는 여유로운 아침입니다.

베이커리

갓 구운 빵의 따뜻한 풍미를 즐겨보세요.

과일
