4. 언제 Grid를 사용할까? 언제 Flexbox를 사용할까?

✅ Grid 사용 권장

  • 2차원 레이아웃: 가로와 세로 모두 제어 필요
  • 복잡한 페이지 레이아웃: 헤더, 사이드바, 메인, 푸터 등
  • 정확한 그리드 구조: 명확한 행과 열 구조
  • 영역 기반 레이아웃: grid-template-areas 사용

✅ Flexbox 사용 권장

  • 1차원 레이아웃: 가로 또는 세로 중 하나
  • 아이템 정렬: justify-content, align-items
  • 동적인 콘텐츠: 크기가 변하는 콘텐츠
  • 네비게이션 메뉴: 가로/세로 메뉴

💡 조합 사용

대부분의 경우 Grid와 Flexbox를 조합하여 사용하는 것이 가장 효과적입니다:

  • 전체 페이지 레이아웃: Grid
  • 헤더/푸터 내부 정렬: Flexbox
  • 콘텐츠 그리드: Grid
  • 카드 내부 요소: Flexbox

5. 실전 패턴 모음

패턴 1: 헤더 (Flexbox) + 메인 (Grid)

header { display: flex; justify-content: space-between; } main { display: grid; grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)); }

패턴 2: 사이드바 (Flexbox) + 콘텐츠 (Grid)

.container { display: flex; } .sidebar { flex: 0 0 250px; } .content { flex: 1; display: grid; grid-template-columns: repeat(3, 1fr); }

패턴 3: 전체 (Grid) + 내부 (Flexbox)

.page { display: grid; grid-template-areas: "header" "main" "footer"; } header { display: flex; justify-content: space-between; } main { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); }
