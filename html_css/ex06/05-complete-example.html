Grid로 만든 웹사이트

Grid와 Flexbox를 조합하여 완성된 레이아웃

🎨

Grid 레이아웃

전체 페이지 구조는 Grid로 구성되었습니다. grid-template-areas를 사용하여 명확한 레이아웃을 만들었습니다.

⚡

Flexbox 정렬

헤더와 푸터는 Flexbox를 사용하여 내부 요소를 정렬했습니다. 각 도구의 장점을 최대한 활용했습니다.

📱

반응형 디자인

auto-fit과 minmax를 사용하여 완벽한 반응형 그리드를 구현했습니다. 모든 기기에서 완벽하게 작동합니다.

🔧

조합 사용

Grid와 Flexbox를 조합하여 복잡한 레이아웃을 쉽게 구현했습니다. 각 도구를 적절한 곳에 사용하는 것이 핵심입니다.
