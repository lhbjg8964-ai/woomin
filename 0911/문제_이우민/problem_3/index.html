문제 1번

[문항1]
반응형 네비게이션 문제 해결 이 페이지는 반응형 네비게이션 구현연습을 위한 문제입니다.
문제 목록:
문제 1: 햄버거 버튼이 PC 화면에서도 보입니다. PC 화면(1025px 이상)에서는 숨겨야 합니다.
문제 2: PC 네비게이션이 모바일에서도 보입니다. 모바일 화면(1024px 이하)에서는 사이드 메뉴로 전환해야 합니다.
문제 3: 모바일 반응형 스타일이 누락되었습니다. 미디어 쿼리를 완성하여 모바일 네비게이션을 구현하세요.
문제 4: JavaScript 기능이 없습니다. 햄버거 버튼 클릭 시 메뉴가 열리고닫히는 기능을 구현하세요.
요구사항:
PC 화면(1025px 이상): 가로 네비게이션 메뉴 표시, 햄버거 버튼 숨김
모바일 화면(1024px 이하):햄버거 버튼 표시, 사이드 메뉴(오른쪽에서 슬라이드) 서브메뉴는 아코디언 형태로 동작
(클릭 시 열림/닫힘) 메뉴 열림 시 배경 스크롤 방지 ESC 키로메뉴 닫기
테스트 방법: 브라우저 개발자 도구(F12)를 열고 디바이스모드로 전환하여 다양한 화면 크기에서 테스트하세요.

문제 2번

[문항2]
요구사항
1. 탭 버튼2개(공지사항, 독서 문화 행사)를 만든다.
2. jQuery를 이용하여 버튼 클릭시 해당 영역의 내용만 보이도록 한다.
- 처음에는 "공지사항"만 보이도록 설정 - 다른 탭 클릭 시 기존 내용은 숨기고, 해당 내용만 보여야 함

문제 3번

[문항3]
요구사항
1. 상위 메뉴를 클릭하면 하위 메뉴가 펼쳐지고, 다시 클릭하면 닫히도록 구현한다.
2. 한 번에 하나의 메뉴만 열리도록 한다. (다른 메뉴 클릭 시 기존 열린 메뉴는 닫힘)
3. 처음 페이지 로드 시 모든 하위 메뉴는 닫혀 있어야 한다.
4. CSS를 사용하여 열림/닫힘 상태를 구분할 수 있도록 시각적 효과(예: 배경색, 아이콘 변화)를 적용한다.
5. jQuery 또는 순수 JavaScript 둘 중 하나를 선택하여 구현한다.
