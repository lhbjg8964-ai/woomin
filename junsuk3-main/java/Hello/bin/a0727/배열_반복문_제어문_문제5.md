## 문제 1. 연속 증가 구간 길이

정수 배열이 주어질 때, **연속으로 값이 증가하는 구간의 최대 길이**를 구하시오.  
(같은 값이면 증가가 아님. 길이는 원소 개수 기준)

**예시**
- 입력: `[1, 3, 5, 4, 7, 8, 9, 2]`
- 출력: `4` → (`4, 7, 8, 9`)

### 정답

```javascript
function maxIncreasingLength(arr) {
  if (arr.length === 0) return 0;

  let maxLen = 1;
  let curLen = 1;

  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > arr[i - 1]) {
      curLen++;
      if (curLen > maxLen) maxLen = curLen;
    } else {
      curLen = 1;
    }
  }

  return maxLen;
}

console.log(maxIncreasingLength([1, 3, 5, 4, 7, 8, 9, 2])); // 4
```

**풀이 포인트**
- 이전 값보다 크면 `curLen` 증가
- 아니면 `curLen`을 1로 리셋
- 지금까지의 최댓값을 `maxLen`에 보관

## 문제 2. 홀수 번째만 합, 짝수 번째만 곱

배열의 **인덱스**를 기준으로
- 홀수 인덱스 값들의 **합**
- 짝수 인덱스 값들의 **곱**
을 각각 구한 뒤, `합 - 곱` 결과를 출력하시오.  
(인덱스는 0부터. 짝수 인덱스가 없으면 곱은 `1`로 처리)

**예시**
- 입력: `[2, 3, 4, 5]`
- 짝수 인덱스: `2 * 4 = 8`
- 홀수 인덱스: `3 + 5 = 8`
- 출력: `0`

### 정답

```javascript
function oddSumEvenProduct(arr) {
  let sum = 0;
  let product = 1;
  let hasEven = false;

  for (let i = 0; i < arr.length; i++) {
    if (i % 2 === 0) {
      product *= arr[i];
      hasEven = true;
    } else {
      sum += arr[i];
    }
  }

  if (!hasEven) product = 1;

  return sum - product;
}

console.log(oddSumEvenProduct([2, 3, 4, 5])); // 0
```

**풀이 포인트**
- `i % 2 === 0` → 짝수 인덱스 (곱)
- `i % 2 === 1` → 홀수 인덱스 (합)
- 마지막에 `합 - 곱`

## 문제 3. 중복 제거 후 두 번째로 큰 수

배열에서 **중복을 제거한 뒤**, 두 번째로 큰 수를 출력하시오.  
서로 다른 값이 2개 미만이면 `"없음"`을 출력하시오.

**예시**
- 입력: `[7, 3, 7, 9, 3, 9, 5]`
- 중복 제거: `[7, 3, 9, 5]`
- 출력: `7`

### 정답

```javascript
function secondLargest(arr) {
  const unique = [];

  for (let i = 0; i < arr.length; i++) {
    let exists = false;
    for (let j = 0; j < unique.length; j++) {
      if (unique[j] === arr[i]) {
        exists = true;
        break;
      }
    }
    if (!exists) unique.push(arr[i]);
  }

  if (unique.length < 2) return "없음";

  // 내림차순 정렬
  for (let i = 0; i < unique.length - 1; i++) {
    for (let j = i + 1; j < unique.length; j++) {
      if (unique[i] < unique[j]) {
        const temp = unique[i];
        unique[i] = unique[j];
        unique[j] = temp;
      }
    }
  }

  return unique[1];
}

console.log(secondLargest([7, 3, 7, 9, 3, 9, 5])); // 7
console.log(secondLargest([5, 5, 5])); // "없음"
```

**풀이 포인트**
- 이중 반복문으로 중복 제거 (또는 `Set` 사용 가능)
- 정렬 후 인덱스 `1`이 두 번째로 큰 수
- 서로 다른 값이 2개 미만이면 `"없음"`

## 문제 4. 구간 합이 target인 부분 배열 개수

정수 배열과 `target`이 주어질 때, **연속된 부분 배열의 합이 target인 경우의 수**를 구하시오.

**예시**
- 배열: `[1, 2, 3, 2, 1]`, `target = 3`
- 해당 구간: `[1,2]`, `[3]`, `[2,1]`
- 출력: `3`

### 정답

```javascript
function countSubarraySum(arr, target) {
  let count = 0;

  for (let start = 0; start < arr.length; start++) {
    let sum = 0;
    for (let end = start; end < arr.length; end++) {
      sum += arr[end];
      if (sum === target) count++;
    }
  }

  return count;
}

console.log(countSubarraySum([1, 2, 3, 2, 1], 3)); // 3
```

**풀이 포인트**
- `start` ~ `end` 이중 반복으로 모든 연속 구간 확인
- 구간 합을 누적하며 `target`과 비교
- 같으면 `count` 증가

## 문제 5. 지그재그 판별 + 변환

배열이 **지그재그**인지 판별하시오.  
지그재그 조건: 인접한 값의 대소 관계가 `작다 → 크다 → 작다 → …` 또는 `크다 → 작다 → 크다 → …`처럼 **번갈아** 나타남.  
(인접 값이 같으면 지그재그 아님)

- 지그재그이면 `"YES"`와 함께, 짝수 인덱스의 값만 모아 새 배열로 출력
- 아니면 `"NO"`만 출력

**예시**
- 입력: `[1, 5, 2, 8, 3]` → `YES` / `[1, 2, 3]`
- 입력: `[1, 2, 3, 4]` → `NO`

### 정답

```javascript
function zigzagCheck(arr) {
  if (arr.length < 2) {
    return { result: "YES", evenIndexValues: arr.slice() };
  }

  // 첫 비교로 시작 방향 결정 (true: 다음이 더 커야 함)
  if (arr[0] === arr[1]) return { result: "NO" };

  let shouldIncrease = arr[1] > arr[0];

  for (let i = 1; i < arr.length; i++) {
    if (arr[i] === arr[i - 1]) return { result: "NO" };

    const isIncrease = arr[i] > arr[i - 1];
    if (isIncrease !== shouldIncrease) return { result: "NO" };

    shouldIncrease = !shouldIncrease; // 다음엔 반대 방향
  }

  const evenIndexValues = [];
  for (let i = 0; i < arr.length; i++) {
    if (i % 2 === 0) evenIndexValues.push(arr[i]);
  }

  return { result: "YES", evenIndexValues };
}

console.log(zigzagCheck([1, 5, 2, 8, 3]));
// { result: "YES", evenIndexValues: [1, 2, 3] }

console.log(zigzagCheck([1, 2, 3, 4]));
// { result: "NO" }
```

**풀이 포인트**
- 첫 두 원소로 “커져야 하는지 / 작아져야 하는지” 결정
- 매 칸마다 기대 방향과 실제 방향을 비교
- 한 번이라도 틀리거나 같으면 `"NO"`
- `"YES"`면 짝수 인덱스만 모아 출력
